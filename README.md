# SEAM Player 🎧

A bold, modern Android music player built for the SEAM ecosystem.

## Stack
- Kotlin + Jetpack Compose
- Material 3
- AndroidX Media3 / ExoPlayer 1.11.0
- MediaSessionService for background playback
- Local Android MediaStore library

## Current experience
- Premium dark UI with SEAM red accents
- Device music scanning
- Play / pause / next / previous
- Shuffle and repeat-one
- Full-screen Now Playing
- Mini-player
- Background playback through Media3
- Home and Library sections

## Roadmap
- Real album artwork from MediaStore
- Search and smart filters
- Favorites persisted with Room
- Playlists and queue editor
- Lyrics screen
- Sleep timer
- Audio effects / equalizer
- Android Auto support
- Gapless playback polish

## Build
Open the project in Android Studio and sync Gradle. The project targets Android 36 and supports Android 8.0+ (API 26+).
